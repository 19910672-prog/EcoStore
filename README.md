# EcoStore v1.0 - proyecto  BTVDS 1.4
** Descripción**
EcoStore es una tienda online desarrollada para el curso BTVDS 1.4. Permite gestionar productos ecológicos y ventas.

**Caracteristicas**
- Gestion de productos
- Carritos de compras
- Panel de administración

  **Tecnologias usadas**
  - HTML / CSS / JavaScript

    **Como ejecutar el proyecto**
    1. Clona el reprositorio: `git clone https://github.com/19910672-prog/EcoStore.git`
    2. Entra a la carpeta: `cd EcoStore`
    3. Abre el archivo `index.html` con doble clic
    4. Listo, se abre en tu navegador
